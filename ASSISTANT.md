# Ассистент чата клуба «СВОИ»

Отдельный бот, который сидит в чате клуба и отвечает на вопросы по статистике НХЛ. Ставок он не даёт.
Платёжный бот (`bot.py`) он не импортирует и не меняет.

- `assistant.py`: сам бот, его характер, правила и решение, когда вступать в разговор.
- `nhl_data.py`: загрузка матчей с официального NHL API в Postgres и подсчёт статистики.

## Запуск на Railway (отдельный сервис)

1. В @BotFather: `/newbot` → имя и аватарка ассистента. Затем `/setprivacy` → выбрать бота → **Disable**.
2. Добавить бота в чат обсуждений клуба и сделать админом (права можно не давать).
3. Railway → проект → **New → GitHub Repo** → `timevlado/tg-bot`. В настройках сервиса:
   - **Branch**: `assistant`
   - **Custom Start Command**: `python assistant.py`
4. Переменные (Variables):
   - `ASSISTANT_BOT_TOKEN`: токен нового бота
   - `ANTHROPIC_API_KEY`: ключ Claude API
   - `DATABASE_URL`: ссылка на тот же Postgres (Add Reference → Postgres → DATABASE_URL)
   - `CLUB_CHAT_ID`: ID чата обсуждений (то же значение, что у платёжного бота)
   - необязательно: `ASSISTANT_NAME` (по умолчанию «Шайба»), `ASSISTANT_COOLDOWN_MIN` (12),
     `ASSISTANT_MAX_PER_HOUR` (4), `ASSISTANT_DAILY_LIMIT` (300), `ASSISTANT_POST_COMMENTS` (1),
     `ASSISTANT_MODEL` (claude-sonnet-5-5)
5. После деплоя бот сам загрузит прошлый и текущий сезоны (займёт минут 10–15) и напишет Владу «база НХЛ загружена».

## Команды (в личке с ботом, только для Влада)

`/status` · `/sync` · `/mute` (сам в разговор не вступает) · `/unmute` · `/chatid`.
Любое сообщение в личке — тест: бот отвечает так же, как ответил бы в чате.

## Как он себя ведёт

- Его позвали (по имени, через @ или ответом на его сообщение) → отвечает сразу.
- Его не звали → вступает только в разговор про НХЛ или в вопрос, который повис. Перед этим ждёт 30 секунд.
  Пауза между такими сообщениями не меньше 12 минут, и не больше 4 сообщений в час. Если сказать нечего, молчит.
- Под новым постом канала про НХЛ оставляет комментарий с 2–3 цифрами к матчу.
- Голы и тоталы считает за основное время.
